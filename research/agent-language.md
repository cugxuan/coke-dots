# Agent 指令语言

由 Coke Dots 维护、发送给模型的任务协议、来源范围、权限、委派、私人记忆规则、附件/续接背景、消息路由、研究工具说明、浏览器规则、结果/CSV 修复提示和摘要关注事项使用中文。工具名、字段名、状态值、参数类型及约束保持原协议。

工具前的 assistant text 会作为进度展示给用户，不是隐藏推理。中文任务的所有可见进度、工具说明、结果 message 和追问均明确要求使用简体中文；其他语言任务按用户的语言，精确回复和必要原文保持原样。

Pi 的默认系统提示、内置 read/bash/edit/write/grep/find/ls 工具说明、参数描述及上下文压缩模板保留安装版本的原文，直接交给供应商，不做字符串匹配或翻译替换。应用规则通过 SDK 的 appendSystemPromptOverride 追加；摘要只通过 session.compact 的额外指令要求保留任务证据、避免重复副作用并使用中文，不改 SDK 的结构和模板。项目、用户、技能、原始对话及历史摘要也保持原文。

英文内容包括 Pi 原生提示与工具描述、工具/JSON/API/命令标识，用户或网页原文、项目/技能文件及历史记录，第三方 SDK/工具返回的错误和日志，以及 Call、Recent activity 等现有界面标签。面向用户的中文要求由应用规则负责，不能保证模型每次完全遵守。

本次恢复 SDK 原生内容透传，保留 DeepSeek 模型配置、权限边界、20 分钟执行上限、21 分钟请求上限和 CSV 验证/受限修复流程。对照结果见 [Pi 原生提示对照](pi-native-prompts-comparison.md)；不据此声称某种指令语言一定更快或模型效果一定更好。
