# Agent 指令语言

由 Coke Dots 维护、发送给模型的任务协议、来源范围、权限、委派、私人记忆规则、附件/续接背景、消息路由、研究工具说明、浏览器规则、结果/CSV 修复提示和摘要关注事项使用中文。工具名、字段名、状态值、参数类型及约束保持原协议。

工具前的 assistant text 会作为进度展示给用户，不是隐藏推理。中文任务的所有可见进度、工具说明、结果 message 和追问均明确要求使用简体中文；其他语言任务按用户的语言，精确回复和必要原文保持原样。

Pi 0.73 的默认基础提示、内置 read/bash/edit/write/grep/find/ls 说明和参数描述在供应商调用边界适配为中文，不改第三方包、执行函数或历史会话。适配仅识别已知 SDK 文本；系统提示中追加的用户/项目/技能正文不改写。摘要对话及已有摘要保留原文，只翻译其标签外的 SDK 说明。SDK 固定摘要标题（如 Goal/Progress）和 XML 标签作为结构标识保留。

仍可能出现英文的内容包括：工具/JSON/API/命令标识，用户或网页原文、项目/技能文件及历史记录，第三方 SDK/工具返回的错误和日志，SDK 附加的部分项目/技能包装标题，以及 Call、Recent activity 等现有界面标签。代码注释、测试名称和翻译匹配表的英文键不等于发送给模型的英文指令。第三方版本变化后需重新核对适配及实际请求，未知文本保留原样，不丢弃未知约束。

本次只更改指令语言及说明，不更改 DeepSeek 模型配置、权限边界、20 分钟执行上限、21 分钟请求上限或 CSV 验证/受限修复流程。不据此声称中文一定更快或模型效果一定更好。
